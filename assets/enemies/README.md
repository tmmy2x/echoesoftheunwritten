# Bespoke enemy asset pipeline

Enemy visual direction is authored specifically for Echoes of the Unwritten: Hollow Wisps (shard cores and torn silhouettes), Clockwraiths (broken clock halos and segmented porcelain masks), Margin Wraiths (ink-cloth bodies and redaction quills), and chapter bosses with distinct telegraphs.

Production asset contract: GLB 2.0, meter-like world units, +Y up, forward +Z, named skeleton, PBR materials, LOD0 and optional LOD1, animation clips `Idle`, `Move`, `Attack`, `Hit`, `Death`, plus `Special` for bosses. Keep gameplay hitboxes separate from rendered geometry.
