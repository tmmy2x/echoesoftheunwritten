# Modular environment asset pipeline

Build regions from reusable GLB modules: floor tiles, cracked path segments, wall sections, pillars, archways, crystal clusters, rift gates, props, and set-piece landmarks. Keep pivots at ground contact, use shared material atlases where possible, and author collision proxies separately.

Art language: Shiverwild = slate, moss, cyan seams; Forgotten City = moonstone, oxidized bronze, amber time shards; Archive at the End = ink-black stone, crimson fissures, floating script fragments, rose emission. Assets are original designs; external models must be license-checked and reworked to this art bible before shipping.
